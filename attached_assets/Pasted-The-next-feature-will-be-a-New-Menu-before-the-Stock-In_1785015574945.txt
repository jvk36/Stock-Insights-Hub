The next feature will be a New Menu before the Stock Insights top menu named 13F Insights. The menu will have three tabs eventually. For this Feature MVP, it will have just one tab titled Funds. The tab will have a card that displays a list of ~50 of the top hedge funds – for this MVP, the list will have just one item – ‘Berkshire Hathaway’. Clicking on the fund should replace the Card with a Card containing a spreadsheet that shows their holdings and other details from 13F Report’s Information Table. Details of the spreadsheet follow (assuming Q1 2026 vs Q4 2025): Total of 8 columns: 1) Name (Ticker): The Name is in the first column of the 13F Information Table (the same name can appear more than once, we should display only one with the rest of the columns summing up based on the name), The Ticker needs to be derived from the third column CUSIP in the Information Table using one of several free sources (SEC’s Official 13F List CSV, OpenFIGI API, Yahoo Finance, or FMP API). Further, some rows that report Calls/Puts and Debt Holdings should be ignored – The SH/PRN and PUT/CALL sub-items under Column 5 determines this – if SH/PRN is NOT SH or if PUT/CALL is NOT Empty, ignore the row, 2) Market Value as of Q1 2026: fourth column (interpret as a dollar value), 3) Shares as of Q1 2026: fifth column (interpret as a number), 4) % Allocation as of Q1 2026: Calculate the percentage figure based on Column 2 with the denominator coming from the 13F Header, 5) Market Value as of Q4 2025: fourth column, 6) Shares as of Q4 2025: fifth column, 7) % Allocation as of Q4 2025: Calculate the percentage figure based on Column 5 with the denominator coming from the corresponding 13F Header, 8) % Change computed from Column 3 compared to Column 6. Color Coding: First and 8th column backgrounds should be color coded as follows - Green for a New Position, Light Blue for <10% increase, Blue for >=10% increase, Light Pink for <10% decrease, Pink for >=10% decrease, otherwise no color. Could you come up with a plan to implement this MVP? Note 1: The data is from SEC 13f Reports at https://www.sec.gov/edgar/browse/?CIK=1067983 (Form Type 13F-HR). For Q1 2026, the 13f is at https://www.sec.gov/Archives/edgar/data/1067983/000119312526226661/0001193125-26-226661-index.htm . Although the data could go further back (depends on the fund), we should limit it to the last ten years (40 quarters). Both the Header and the Information Table have XML data which should make it easy to read, Note 2: Will need to use a DB to store quarterly 13F info to avoid having to hit the SEC servers every time. The DB should be designed to store quarterly data for all the hedge funds we will eventually track. The comparison spreadsheet displayed to the user is dynamically built as users browse, Note 2: Updating the DB need to be done only around once a day or so, as the 13f reports only happen once a quarter, Note 3: Consider that following enhancements that will need to be added after the MVP is fully functional – a) Around 50 of the Top Funds will need to be incorporated as opposed to just one for the MVP, b) Hovering over a row in the spreadsheet should show the Price Range of the stock during the quarter, b) Underneath the spreadsheet, there should be a Section that shows the News Headlines of the Fund, c) Next to the Hedge Funds Tab will be two more tabs – one showing “Summary Stats” such as ‘Most Popular Stocks”, “Top Buys”, “Top Sells”, “Top Stocks Near 52-week Lows”, etc. on Several Cards. Clicking on a stock in any of these Summary Cards should switch to the third tab titled “13F Ticker Analytics” with three Sections: 1) An Overview Section showing Ticker, Company Name, Current Price, and a Price Chart, 2) Aggregate Ownership Sentiment Section showing a visual sentiment bar indicating institutional conviction (e.g., 7 funds Buying, 2 Funds Selling, 12 Funds Holdings), and 3) Historical Institutional Trend Chart Section: A bar chart showing total shares held by all top hedge funds combined over the last 4 to 8 quarters. This makes it instantly obvious if smart money is accumulating or distributing the stock over time.
