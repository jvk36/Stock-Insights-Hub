---
name: NAV valuation inputs
description: Distinguishes reported balance-sheet inputs from fair-market assumptions in NAV models.
---

Use the latest reported carrying value of properties or primary assets as a starting point, derive reported other assets from total assets, and keep the fair-market value of the primary assets explicitly editable.

**Why:** Balance-sheet carrying values are not independent appraisals. Presenting them as fair market value would create false precision, especially for REITs, holding companies, funds, and natural-resource businesses.

**How to apply:** Show reported carrying values separately from valuation assumptions. Use total liabilities rather than only debt, calculate NAV per share from the edited assumptions, and label the result as an estimate.
